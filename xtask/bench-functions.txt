#
#   name<TAB>template[<TAB>error|note]

# Read by `crates/engine/examples/bench_functions.rs` (which measures it) and by
# `cargo xtask bench-functions --check` (which fails when a registered function has no line).
# Templates were generated from each function's signature; a line whose call the engine refuses
# is fixed by hand once the page shows it.
#
# Tokens (all sizes are over the prepared workbook: header row 1, data from row 2):
#   $R    A2:A{last}  ids (numbers)        $R2   B2:B{last}  quantities
#   $R3   C2:C{last}  prices               $RT   D2:D{last}  item names (text)
#   $E    E2:E{last}  regions              $F    F2:F{last}  dates (text)
#   $RD   F2:F{last}  dates                $T    G1:H{last}  a table (text key, value)
#   $TN   A1:C{last}  a table (number key) $KG   G2:G{last}  the key column
#   $RH   H2:H{last}  the value column     $K    a key in $T      $KN  its number
#   $DATE 46317       a date serial
#   $RS   B2:B{cap}   a series' values    $TS   A2:A{cap}   its timeline
#   $LS   {cap}       the series' last point. The cap is 200,000 rows — the longest series the
#                     FORECAST.ETS family accepts — so a whole column of a million rows is not
#                     what $RS/$TS expand to.
# `small` makes each range ten rows, `whole` the whole column; a template with no token is
# scalar and is measured once. The optional third field is `error` (the function's documented
# answer is an error here) or a note the page prints beside the row.
