One formula,
more than one cell.

Cella has 500+ formula functions. An array formula can spill into adjacent cells, so one expression can generate a whole range. Use LET and LAMBDA to build reusable logic and structured references to work with table columns by name.

Open the files
you’re sent.

Read and write .xlsx, import Excel 97–2003 .xls files, and work with CSV or TSV. Turn rows into tables, summarize them in PivotTables, and chart the results.

Still in alpha. Excel compatibility is a work in progress. Try a copy of an important workbook and check its formulas and layout after saving.

The same sheet,
scriptable.

The desktop app, CLI, MCP server, and control channel share the same workbook commands. Set a cell, fill a range, or save a workbook from another tool.

From the source checkout, evaluate the 100-copy preset:

cargo run -p cella-cli -- eval "=SUM(60,100*0.20)/100"
