# Cella / Open Print

**Direction.** The pinned brief calls for a large-format modernist manifesto: warm ivory, cinnabar, oversized type, and hard rules. The first fold reads left to right as a poster. The original vector plate turns two sheet grids into an open workbook: ordinary cells on one page, an array spilling from B2 on the other. It is an illustration, not an app preview or a live grid.

**Reading order.** The visitor gets releases, source, and a docs route up front. A real bundled workbook and three linked evidence rows show what to test on a copy of their own XLSX file. The first plate’s formula reappears in a cinnabar spread routing one engine command to four entry points. The source quick-start, docs, and contributor guide close the page. At narrow widths the copy and actions precede the plate.

**System.** Paper `#f8f2e7`, ink `#231c18`, and cinnabar `#a82d20` drive all surfaces; a darker red is used for small links on paper. Local sans type is paired with monospace only for notation and commands. Native links and anchors are the only controls. The sole transition is a short button color change, omitted under reduced motion.
