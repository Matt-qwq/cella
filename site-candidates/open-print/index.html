The workbook
is the point.

Open an .xlsx file, edit it in the grid, and save it as XLSX. Cella is in alpha, and Excel compatibility is still in progress. Try a copy of a workbook you rely on before switching.

  • Read and write XLSX

    Read and save formatting, validation rules and comments alongside your data.

    File-format status

  • 500+ formula functions

    Use LET and LAMBDA, or spill the results of a dynamic array across cells.

    Function coverage

  • Tables, PivotTables and charts

    Filter a table, group dates in a PivotTable, and chart the results.

One engine.
Four ways in.

Enter a formula in the grid or set it from a script: both use the same engine command. The desktop app, CLI, MCP server and control channel all run on that model.

cell.set

{"cell": "B2", "input": "=SEQUENCE(3,2)"}
