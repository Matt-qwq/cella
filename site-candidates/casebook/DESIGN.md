# Casebook

**Direction.** A daylight exhibition guide, not a simulated app. Warm bone (`--paper`), forest-teal ink, Palatino/Georgia display type, plain system UI for reading, and square window mats. The actual workbook renders carry the color. The reference section inverts the palette to separate documentation from the exhibits.

**Signature.** Two staggered worksheet details are links to the studies they preview. The same numbered labels appear in the exhibit index and at the destination; the destination's label fills in on arrival. Wide layouts overlap the mats without obscuring their captions. On narrow screens they step down the page, and the budget study opens up a closer view of the variance columns. Budget → sales pivot → print proof moves from reading a sheet to shaping a report to preparing a page.

**Interaction.** Native links and focusable fragment targets work without scripting. Each study links to the uncropped render. There is no carousel, automatic motion, or scroll hijacking; optional hover cues respect reduced motion. Releases, source and Docs are visible before the exhibits.
