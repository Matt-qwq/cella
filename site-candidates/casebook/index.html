Workbooks, up close.

Cella is an independent, open-source spreadsheet built in Rust. Explore three jobs: tracking a budget, summarizing sales, and preparing a sheet for print.

01

Review monthly spending

Put planned and actual spending side by side. Here, dining out came in $65.90 over budget. The Difference column gives you the amount; the color scale shows how much of the budget each category used.

02

Group revenue by region

Start with a list of orders. Put Region in rows and Product in columns, then sum Revenue. Use the Channel filter to narrow the report without changing the source rows.

03

Check the page before printing

The monthly budget returns in Page Break Preview. The blue divider runs through the chart: a split you can catch and correct before you print or export to PDF.

Compatibility & automation

Workbook support

Cella’s clean-room spreadsheet engine reads and writes .xlsx, with 500+ formula functions, dynamic arrays, tables, PivotTables, and charts. Excel compatibility is still a work in progress. Start with a copy of any workbook you rely on.

  • File-format compatibility
  • Performance measurements

One command model

Changing a cell in the desktop grid runs the same cell.set command a script can call. Run workbook commands headless through the CLI or MCP server, or use the control channel to drive a running desktop session.
