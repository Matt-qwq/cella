## Position

Cella is the spreadsheet for **data and agents**: it opens the files people actually receive
(`.xlsx`, `.xls`, password-protected), holds a real data set (the query pipeline, Parquet, the DAX
data model), lets a program drive every action (MCP, control channel, CLI), and treats performance
as a product feature. English and Simplified Chinese, deliberately.

It is **measured against Microsoft Excel only**. This repository does not track
`storytold/gridcraft` — the line it forked from at v0.11.1 — as a deliverable: the 18-batch adoption
round of 11-16 was the last planned port, there is no adoption queue and no "parity with upstream"
figure, and histories are not merged (284 files were rewritten on both sides). The `upstream`
remote stays configured as a **read-only reference** — "has upstream already fixed this?" is a fair
question when a user reports a gap — but anything taken lands here as our own work with our own
tests.

**Not built on purpose:** Python cells (`crates/sandbox`), equation layout (`crates/math`,
`ratex`), twelve-language catalogs, real-time collaboration, mobile clients, an in-app assistant.
Each is a decision with a date, not an omission; the record is in [docs/roadmap.md](docs/roadmap.md).

calibration](docs/target-app-parity.md#effort-and-calibration) (~6–10 h per readiness point for the remaining, verification-heavy
work; single features measured from PRs #66, #100, #101). Parallelism: the full and mainstream
work splits ~65–70% across 4–6 agents by area; the essentials work is mostly small fixes plus one
long `.xls` track, so about half parallelizes (≈30–50 wall-clock hours with three agents).

Why alpha: all six core workflows in the [alpha gate](docs/roadmap.md#alpha-gate) pass end to end
on macOS with save and reopen, and the large-workbook beta gate is now met: 100M cells open with
16.7 MiB live / 183 MiB peak, independent formulas recalculate on the machine's threads (100k edit
20–25 ms), row and column structural edits are maps rather than cell moves, and whole-sheet data
commands are bounded. The remaining beta work is external: **the real-world corpus ran on 11-03**
— 3,084 workbooks opened with no reader failure, 635 save/reopen cycles with zero mismatches, and
Excel 16 found Cella's copies identical (16 `.xlsx` files compared; all 37 readable `.xls`
converted and matched) — so #1 is met in substance, with the pinned, sha-verified corpus left for
CI. A `.xls` file still loses OLE objects, controls and chart sheets (charts, pictures and shapes
are read), and the field reports of GPU crashes and freezes still need the machines they came from
(#10). Everything else that blocked beta is met: pass-through (#3), charts (#4), all-script text
(#5, with a font-coverage caveat), calculation correctness (#6), PivotTables (#8) and keyboard
access (#9). What remains is #10 and the release run (see [beta gates](docs/roadmap.md#beta-gates)).

The 2026-10-07 numbers (catalog 89%, "feature depth ~65%", "~215 h to full parity") were
re-measured. Catalog and function counts held or rose; the depth and hours moved because of new
evidence: 82 issues filed by users and contributors in the repo's first five days, and scope the
old estimate left out (localization, legacy `.xls`, Power Query and the data model,
collaboration, mobile, AI).
